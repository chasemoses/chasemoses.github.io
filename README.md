# chasemoses.github.io

My portfolio site: React 19, TypeScript, and Vite, deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Project content lives in [`src/data.ts`](src/data.ts); screenshots and the PDF version are in `public/`.
